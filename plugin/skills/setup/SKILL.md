---
name: setup
description: Проверить готовность Compose Visual Bridge после установки плагина и объяснить первый запуск редактора.
---

Корень установленного плагина — на два каталога выше этого SKILL.md. Все команды запускайте по абсолютному пути; не используйте путь к исходному репозиторию.

Выполните `node <plugin>/scripts/plugin.mjs setup`. Если Node.js отсутствует или старше версии 20, сообщите необходимое требование. Не запускайте npm install и не создавайте пользовательские макеты во время setup. Готовый редактор входит в пакет.

При успешной проверке объясните: «Попросите открыть конкретный Compose-экран этого проекта в визуальном редакторе. Сначала сравните исходный макет с настоящим экраном и подтвердите его в редакторе. После ручных правок нажмите “Передать агенту”, затем поручите перенос в код». Для поддерживаемого Kotlin доступен проверяемый браузерный импорт с переносом правок; инструкция — docs/browser-compose.md. Нативный Compose Preview через Buddy служит эталоном. Для настоящего UI нужен Node.js 22+; подготовка отдельного Android-стенда и автоматическое обнаружение Preview описаны в docs/native-ui.md и требуют JDK 21/Android SDK. Сессии сохраняются отдельно от исходников проекта и установки плагина. Пользователь не выбирает порт или каталог данных. Сохранённые экраны доступны через list; автоматический каталог всех состояний приложения пока не реализован.

Проверьте отдельно `native.nodeReady` и `native.buildReady`: `ready=true` подтверждает комплект редактора, но не Android toolchain. Назовите конкретно отсутствующие Node 22+, JDK 21+ или Android SDK. Найденные пути выводятся в setup; системную Java менять не требуется. Основной путь редактирования элементов — edit-compose (либо edit-scene для подготовленного runtime-адаптера) по docs/browser-compose.md. Для эталонного PNG доступны prepare-native → native-build → create-native → native-run; PNG с рамками не является редактором элементов. Текущая сцена работающего приложения использует отдельный debug-адаптер по docs/live-app.md, его расширенная Android-приёмка ещё открыта. На этой машине выделяйте тестовый эмулятор через android-emu и освобождайте аренду после проверки; физический телефон не использовать.

Каталог сохранённых экранов и состояний, отдельный новый экран с запросом и палитра проекта доступны в управляемой браузерной сессии. Наличие этих функций не подтверждает импорт любого экрана. При диагностике различайте комплект редактора, Android toolchain, успешную сборку и принятый нативный захват.
