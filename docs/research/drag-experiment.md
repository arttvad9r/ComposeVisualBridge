# Эксперимент с перетаскиванием — 10 октября 2026

## Решение

В редактор подключён `@dnd-kit/dom 0.5.0`. React не нужен. Библиотека управляет сенсором указателя, порогом активации и отменой. Наш адаптер определяет место вставки, а модель проверяет перенос и создаёт одну запись истории. DOM не становится источником истины.

`@atlaskit/pragmatic-drag-and-drop 4.0.0` остаётся dev-зависимостью для стенда `/lab`. Оба варианта работают локально, без CDN. `esbuild 0.28.2` собирает браузерные модули перед запуском. Исходники сторонних проектов не копировались; используются опубликованные пакеты с сохранением лицензий в THIRD_PARTY_NOTICES.md.

## Что проверено

Проверки выполнены во встроенном браузере Codex через отдельную сессию на порту 4180. Стенд не обращается к API сессии.

| Проверка | dnd-kit/dom | Pragmatic DnD |
|---|---|---|
| Перестановка a после b в дереве | Прошла | Прошла |
| Undo возвращает порядок | Прошла | Модель общая; отдельно не проверено |
| Видимый индикатор при движении | Линия следует за указателем | В быстром синтетическом drag индикатор отстаёт; финальный drop правильный |
| Перенос из макета в контейнер дерева | Прошёл в редакторе | Не проверено |
| Esc оставляет документ неизменным | Прошла в редакторе | Не проверено |
| Сохранение и тестовая передача после drag | Прошла в редакторе | Не проверено |
| Быстрый ввод текста → Apply в 767 × 718 | Полный текст попал в снимок | Не проверено |
| Черновик после Apply, загрузка страницы | Снимок сохранён, различие показано | Не проверено |

Это функциональная проверка небольшого сценария, не бенчмарк и не доказательство общей надёжности библиотек. Native drag может иначе вести себя при обычном движении мышью; наблюдение об индикаторе ограничено нашим стендом и способом воспроизведения.

Выбор dnd-kit обусловлен PointerSensor, поддержкой отмены и соответствием прежнему взаимодействию редактора. Pragmatic использует native HTML Drag and Drop. Часть клавиатурных возможностей dnd-kit сейчас не подключена: перенос без мыши выполняется существующими кнопками в разделе «Перемещение». Сенсоры touch/pen, автопрокрутка, перекрывающиеся Box и браузер Claude остаются отдельными проверками.

## Воспроизведение

```sh
npm ci
PORT=4180 BRIDGE_DATA=./data/dev npm start
```

Открыть `/lab`: выбрать библиотеку, перетащить a к нижнему краю b, проверить JSON и Undo. На `/` выбрать title, перетащить его из макета в центр serverCard в дереве. Проверить diff, Undo и Esc. По окончании создать тестовый снимок и прочитать отчёт.

Не использовать пользовательские данные для таких проверок. Полностью автоматического браузерного набора пока нет; Node-тесты проверяют модель и файловый контракт, а не сенсор.
