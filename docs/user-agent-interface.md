# Пользовательский интерфейс и данные для агента

Обзор текущих панелей, 11 октября 2026. В редакторе макета технические инструменты перенесены в «Дополнительно», связь с Kotlin убрана из обычного инспектора, ID заменены названиями, список правок использует понятные обозначения. Сведения для агента в API и снимках сохраняются. Нативный просмотр PNG остаётся отдельным режимом диагностики.

| Функция | Пользователю | Агенту |
| --- | --- | --- |
| Сравнение | До / После | Настоящий Android-кадр, проверка соответствия макета |
| Передача | Одна кнопка, статус сохранения | Неизменяемый снимок, исходное и изменённое дерево, статус проверки |
| Элементы | Название, текст, тип, выбор и иерархия | Стабильный ID, путь экземпляра, привязка к Kotlin |
| Связь с кодом | Скрыть из обычного инспектора | Файлы, символы, строки, кандидаты и ревизия исходников |
| Изменения | Понятный перечень правок, возможность проверить переданное | JSON, технические frames, точный diff и отчёт |
| Подключение Android | Понятные названия экранов и состояние загрузки | WebSocket, ADB, workspace, Preview FQN, digest, density и сборка |
| Проверка макета | Сообщение, если редактор пока не готов | Сопоставление с настоящим экраном; не выдавать ошибку реконструкции за правку пользователя |
| Файлы | Импорт, экспорт и восстановление в «Дополнительно» | JSON/API и история сессий |
| Сбой или конфликт | Что случилось и как сохранить работу | Ревизии, диагностика и причины конфликта |

Оставить доступными визуальные свойства, адаптивную/свободную компоновку, порядок и вложенность, создание/удаление элементов, Undo/Redo, масштаб и выбор размера экрана. Раздел «Связь с кодом», технические ID в названиях и постоянные пояснения не нужны для этих действий. Подсказки показывать по запросу.

Кнопка «Удалить элемент» находится вверху инспектора, под названием выбранного элемента. Delete удаляет выбранный элемент, если фокус вне поля ввода; корневой контейнер защищён. Контейнер удаляется вместе с детьми. Удаление можно отменить через Ctrl+Z или кнопку Undo; оно сохраняется в черновике и передаётся агенту в общем снимке.

Не скрывать от пользователя потерю связи, несохранённые правки или невозможность редактирования. Вместо технических подробностей давать короткое объяснение и действие; подробности оставлять агенту.
