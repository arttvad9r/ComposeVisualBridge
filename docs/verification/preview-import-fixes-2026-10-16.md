# Исправления импорта Preview — 16 октября 2026

Версия 0.10.7 исправляет четыре проблемы, найденные в аудите 0.10.6. Пользовательские сессии, основные профили плагинов и Android-проекты не менялись. Для тестов использованы временные BRIDGE_DATA и свободные порты.

## Поведение после исправления

1. `edit-previews` сохраняет настоящий JVM-кадр как эталон, но создаёт сессию с `verification=null`. До сверки пользователем доступен только тестовый снимок; обычный `review` возвращает 422. Проверка выполняется через «Дополнительно → Исходник не проверен».
2. Прежнее `confirmedBy=render` не подтверждает новый baseline. Чтение старого review через `/api/handoff` также возвращает 422. Файлы старого снимка остаются неизменными; пользователь может сверить макет и создать новый снимок.
3. Генератор возвращает диагностику неизвестных вызовов в UI-содержимом, включая ветки и именованные слоты. При такой диагностике автоматический `edit-previews` прекращается до Gradle и создания сессий, сообщая файл, функцию, вызов и причину. Функции с неподдерживаемым телом-выражением больше не теряются молча. Обычные аргументы, обработчики событий, эффекты, состояния и распознанные значения не считаются UI-компонентами.
4. `.bridge-previews.json` исключён из хеша исходников. Возвращённые `sourceRevision`/`workspaceRevision` соответствуют восстановленной копии; изменение служебного manifest не меняет ревизию, изменение Kotlin — меняет.
5. Любой ненулевой код завершения Gradle прекращает импорт, даже если уже записаны кадры. В ошибке есть код и путь к логу. Существующие handoff и latest-сессия сохраняются.

Версия пакета повышена, чтобы управляемый запуск отличал исправленный сервер от уже работающего сервера 0.10.6. Обновлены README, протокол, инструкция агенту и skill внутри собираемого плагина. Установка в основные профили Codex/Claude Code и push не выполнялись.

## Ограничения

Генератор остаётся консервативным сканером Kotlin, а не компилятором: диагностика не доказывает полноту произвольного UI. Обнаруженный неподдерживаемый вызов, даже в условной ветке, останавливает автоматический импорт проекта. Это явный отказ, а не добавленная поддержка Canvas/AndroidView/сторонних компонентов. Для такого проекта нужен полноценный явный адаптер или отдельная воспроизводимая сцена; сравнение с кадром обязательно и для них.

При чтении текущих исходников Mealio обнаружены неподдерживаемые визуальные вызовы, в том числе FlowRow, AlertDialog и AsyncImage; автоматический импорт теперь сообщает о них вместо молчаливого неполного представления. Исходники Mealio не изменялись. Этот статический просмотр не является нативной приёмкой.

Новые сборки реальных Android-проектов, JVM-отрисовки их Preview и ADB-захваты не выполнялись. Общая сквозная приёмка остаётся открытой в плане разработки; зелёные Node/Chromium-тесты не заменяют её.
