# Исправления аудита — 11 октября 2026

Проверена незавершённая рабочая копия 0.8.1 после [аудита A1–A8](project-audit-2026-10-11.md). Исправления уже присутствовали при возобновлении работы; добавлены проверки лимита HTTP по байтам, конфликтного импорта, отказов native Apply/Undo и аварийного завершения инструментирования. Уточнены README, требования Node.js, версия архива и постоянная документация. Пользовательские данные, установленный профиль и внешние Android-проекты не изменялись.

| Проблема | Фактическое исправление и проверка |
|---|---|
| A1, UTF-8 | Buffer объединяются перед декодированием; разрыв внутри кириллицы и emoji сохраняет текст. Лимит считается по байтам: JSON меньше двух миллионов символов, но больше двух миллионов UTF-8 байтов получает 413 без изменения сессии. |
| A2, импорт | Актуальный документ отправляется через очередь сохранения до импорта; ввод блокируется на время операции. Chromium проверяет мгновенный импорт, архив последней правки и восстановление. Отказ записи и конфликт останавливают импорт, сохраняя локальный текст; при конфликте проверен экспорт этого текста. |
| A3, запись Kotlin | Инструментирование и восстановление используют `storage.mjs`: временный файл и атомарную замену, исключительное создание helper. Проверены частичная запись при инструментировании/восстановлении обоих адаптеров, отказ rollback сцены с сохранением манифеста и последующее восстановление. Отдельный дочерний процесс завершён SIGKILL после замены первого из двух файлов: оригиналы остаются в манифесте, оба файла восстанавливаются; повторное восстановление также проходит. |
| A4, padding | Генерируется один padding с эффективными значениями осей, включая ноль и сброс оси; горизонтальное переопределение не складывается с общим отступом. |
| A5, порядок Modifier | Существующий вызов заменяется на прежнем месте относительно padding. Проверены width до/после padding, requiredWidth и изменение одной оси size с сохранением другой. Повторяющиеся пересекающиеся модификаторы отклоняются как неоднозначные и требуют агента. |
| A6, enabled | Удаление свойства удаляет Kotlin-аргумент; повторный импорт получает значение по умолчанию. Callback остаётся в исходнике. |
| A7, Node-набор | PNG-тест создаёт самостоятельный Image-документ без frames предыдущего дерева; валидатор продолжает отклонять несогласованную геометрию. |
| A8, native-статус | Неуспешная операция сохраняет статус ошибки, включая последующий опрос сервера. Проверены confirm, Apply и Undo; отказ сохраняет снимок/историю, успешная операция снимает ошибку. |

Проверки текущей копии:

- `npm test`: 66 из 66 Node-тестов прошли; штатная команда также собрала редактор и архив плагина 0.8.1. Тесты пакета проверили запуск после переноса/распаковки, сохранность снимков, остановку и возобновление на отдельных данных.
- `npm run test:browser`: 51 из 51 Chromium-сценария прошли. После добавления двух сценариев конфликтного импорта и отказов Apply/Undo они отдельно запущены через `--grep`; оба прошли. Всего проверены все 53 сценария текущего набора.
- `node --check`: server, app/native controllers, compose, scene, storage, изменённые Node/Chromium-тесты и сборщик пакета — без ошибок.
- `git diff --check`: без ошибок.

Для тестов использованы отдельные временные каталоги данных и свободные порты. Песочница запретила запуск `tar` при первой попытке `npm test`; штатные проверки и Chromium затем выполнены с разрешением вне песочницы.

Изменения A4/A5 проверены по сгенерированному Kotlin и поддерживаемой модели. Новая Android-сборка и измерение настоящих границ после этих исправлений не выполнялись: визуальная приёмка остаётся в шаге 3 [плана готовности](../plans/development.md). Пакет собран и проверен тестами в отдельной копии; обновление установленного пользовательского плагина и новая беседа Codex не выполнялись. Прерывание процесса не доказывает устойчивость к потере питания или отказу оборудования; временные файлы после аварии могут потребовать отдельной очистки. Приёмка B2/B6/B7 и выпуск целиком не объявлены завершёнными.

Последующая проверка: [настоящие Android-границы A4/A5](android-geometry-2026-10-11.md) получены до и после двух итераций. Порядок Modifier и замена отступов подтверждены; выявленные расхождения браузера с Android оставляют визуальную приёмку открытой.
