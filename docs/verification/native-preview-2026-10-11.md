# Проверка оригинального Compose Preview — 11 октября 2026

## Результат

Bridge 0.4.0 показал оригинальный SettingsScreen Mealio через опубликованный Compose Buddy 0.3.0: PNG 1216×2640, densityDpi=560, 34 семантических узла. HTML-версия экрана не создавалась. Выбор заголовка «Подключение» в браузере совпал с нативными bounds (112,98)–(421,154); максимальное отклонение рамки после масштабирования — 0,01234 CSS px. Это проверка геометрии overlay, а не сравнение двух независимых рендереров.

Создана тестовая review-передача с пожеланием fontSize=16 sp. Подтверждение сцены моделировалось только в изолированном acceptance-стенде, не от имени пользователя в его сессии. После изменения оригинального Kotlin в disposable-копии, сборки и установки APK новая съёмка показала 16.0.sp вместо 13.5.sp, другой digest и SHA. Старый handoff с первоначальным PNG и намерением остался неизменным. Подтверждение нового кадра сбросилось.

После перезапуска Bridge и установки окончательной тестовой сборки повторно проверены оригинальный кадр, автозаполнение фактического размера шрифта, переходы Light → Dark → Light через каталог, отсутствие pageerror и неизменность прежней передачи. SHA окончательной тестовой сборки: `349b831a4a5efc888c9f4bd23ae7be97fd1a5c8d77cbc0ca49965a7cee860314` (детерминированный SHA-256 файлов тестовой копии, исключая build/.gradle/local.properties).

## Стенд и совместимость

Изменения runtime, compiler, тестовых сцен и шрифта выполнены только в `/tmp/cvb-buddy-acceptance-…/project`. Основной Mealio, существующая проверочная копия и пользовательские сессии Bridge не изменялись этой проверкой.

JDK 17, AGP 8.9.2, compileSdk 36; Kotlin/Compose compiler обновлены в disposable-копии с 2.1.0 до 2.3.20. Buddy runtime подтянул Compose 1.10.6, Activity 1.13.0 и Ktor 3.4.2. Собран и установлен debug APK. Проверен ручной BuddyPreviewRegistryImpl с двумя обёртками оригинального SettingsScreen и MealioTheme: русский язык, светлая/тёмная тема, fontScale=1, синтетический ServerAccount, пустые обработчики действий, без серверного аккаунта и запросов сети. KSP-обнаружение не проверялось.

Отдельный новый AVD: API 36, Google APIs Play Store, 1216×2640, 560 dpi, SwiftShader, 2048 MB, serial emulator-5580. Существующий пользовательский AVD не запускался и не менялся. Activity работала без action bar и системных inset; origin=(0,0). Собственный adb forward и отдельный BRIDGE_DATA на свободном порту. Node.js 26.11.1.

Новое поколение Compose lint обнаружило четыре несовместимых обращения к Configuration/строковым ресурсам в тестовой копии. Они заменены на LocalConfiguration/stringResource только там. Итоговые assembleDebug, testDebugUnitTest и lintDebug прошли: 289 тестов, 0 ошибок/пропусков, lint без ошибок (30 предупреждений). Instrumentation-набор Mealio повторно не запускался; нативная проверка выполнена через настоящий debug Preview и Playwright.

## Исправления, найденные реальным запуском

Опубликованный runtime принимает команды с discriminator `cmd`; ответы имеют `type`. Это учтено в адаптере и регрессионном WebSocket-тесте. Activity открывает порт не сразу: начальное подключение повторяется до 10 секунд, проверено тестом отложенного запуска. При переключении сцены интерфейс ждёт новый кадр перед следующим переходом. Buddy шлёт fontSize как `16.0.sp`; автозаполнение выделяет число без лишней точки, проверено в Chromium.

В этой версии Compose Buddy не дал ни одной source.file/line (0 из 34 узлов). В редакторе показано отсутствие ссылки, source.confidence=unknown; в намерениях sourceRequiresResolution=true. Сопоставление с Kotlin остаётся задачей агента. Ссылки из других runtime-конфигураций также считаются подсказками, которые нужно проверить.

## Границы результата

Работает отдельный зарегистрированный Preview, включая оригинальную тему и нужные тестовые данные. Каталог не является автоматическим полным перечнем состояний приложения. Подключение требует debug-адаптера и совместимого Android toolchain. Нет автоматического точного source mapping, исполнения Android-кликов, live patching Kotlin и свободного drag/resize поверх изображения. Сохранённое намерение не меняет PNG; результат проверяется после переноса кода и новой сборки. Перенос в основной Mealio и установку плагина в основной профиль эта работа не выполняла.
