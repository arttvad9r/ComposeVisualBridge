# Воспроизводимые браузерные сценарии редактора

Первый шаг этапа 1, требования R3–R7 и R11. Это ручная исходная проверка перед исправлениями и автоматизацией. Команда запуска стенда не является браузерным тестом.

## Запуск и условия

Из корня проекта: `npm run browser:scenarios`. Команда собирает браузерный код, валидирует [макет](../../examples/browser-scenarios.json) и запускает сервер на свободном loopback-порту с новым временным BRIDGE_DATA. Открыть URL из терминала. Пользовательская сессия не используется. Ctrl+C останавливает сервер и удаляет временные данные; аварийное завершение может оставить каталог в системной временной папке.

Макет содержит 12 узлов: `source` → `nested` → перекрывающиеся `first` и `second`, кнопку `movable`, контейнер `target` и нижний `bottom`. Ссылок на внешний проект нет; sourceRevision — `browser-fixture-only`.

Начальные условия: viewport браузера 1280×720, свободная компоновка. Для координатных жестов выбрать «Только макет» и масштаб 65%. Перед каждым независимым сценарием восстановить документ через Undo до нулевого diff либо перезапустить стенд. Кнопка «Сбросить» сама создаёт отменяемое действие. Перед перезагрузкой дождаться «Черновик сохранён ✓».

Дерево и макет прокручиваются отдельно. Прежде чем тащить, убедиться, что оба конца жеста видны: прямоугольник элемента из DOM может лежать за обрезающей границей панели. После прокрутки, изменения масштаба или рендера координаты получить заново. Двигать указатель дальше порога активации 5 px, затем к цели и отпускать; одного клика недостаточно.

## Сценарии и критерии

| ID | Действия | Ожидаемый результат |
|---|---|---|
| B01 | Viewport 900×600, 65%, прокрутить canvas до `bottom`; затем вернуть viewport | Страница без горизонтального переполнения; нижний элемент виден после прокрутки; дерево доступно через свою прокрутку |
| B02 | На макете выбрать `second` в перекрытии с `first`; затем выбрать `nested` в дереве | Выбран точный ID, одна рамка с восемью ручками; документ и diff не меняются |
| B03 | Из дерева перенести `first` в пустой центр `target`, Undo; повторить на верхнем краю (около 7% высоты) `target` | Центр: `first` — ребёнок `target`. Край: `first` — ребёнок `screen` перед `target`. Сообщения «Внутрь target» и «Перед target»; Undo возвращает исходный документ |
| B04 | Начать движение `second` на макете, после активации нажать Esc и отпустить указатель | «Перемещение отменено», нулевой diff, нет активного drag или оставшихся индикаторов; документ не меняется |
| B05 | Прокрутить дерево до `movable` и `target`; перенести `movable` в центр строки `target`, Undo | `movable` становится ребёнком `target`, остальные ID сохранены; Undo восстанавливает исходную вложенность |
| B06 | Начать движение `second` на макете и отпустить над строкой дерева `title`, Undo | Это визуальное смещение: родитель остаётся `nested`, порядок дерева прежний. Перенос родителя доступен жестом, начатым в дереве |
| B07 | Viewport 900×600, прокрутить canvas до `bottom`; прокрутить дерево до последних строк | Обе панели прокручиваются; после прокрутки выбирается нужный видимый элемент; позиции целей вычисляются заново |
| B08 | Выбрать `second`, потянуть правую ручку на 26 px при 65%; Undo, Redo, Undo | Ширина 130 → 170 dp; родитель и соседи неподвижны. Undo возвращает точный исходный документ, Redo возвращает изменение |
| B09 | Раскрыть «Размер», оставить «Оформление» закрытым; изменить ширину `second` на 140.5 и убрать фокус | Ширина меняется, разделы сохраняют раскрытие. Другие свойства не меняются |
| B10 | Начать resize и нажать Esc до отпускания; затем сфокусировать правую ручку и нажать ArrowRight, Undo | Отменённый resize не меняет diff. Клавиатурный resize создаёт одну отменяемую правку |
| B11 | Изменить ширину `second` на 140.5, дождаться сохранения, перезагрузить страницу | Восстановлена ширина 140.5 и исходная вложенность. История Undo после перезагрузки пуста — текущее ограничение |

Для сравнения полного документа использовать GET `/api/session`: `current` после Undo должен совпадать с сохранённым исходным `baseline`, включая отсутствие ранее несуществовавших `layout.frames`. Нулевой счётчик diff сам по себе не доказывает точное восстановление. Геометрию проверять в макете; количество изменений не фиксировать: diff также учитывает порядок соседей и сохранённые frames.

## Исходная проверка 11 октября 2026

Выполнено во встроенном браузере Codex на отдельной временной сессии, viewport 1280×720 и 900×600. Подтверждены выбор `second`, переносы из дерева в дерево и в центр/край макета, визуальное перемещение с макета к дереву без изменения структуры, Esc для drag и resize, resize с Undo/Redo, клавиатурная ручка, раскрытие разделов при дробном размере и прокрутка. После отмены изменений сравнение `current` и `baseline` в session.json подтвердило точное равенство; applied остался null.

После сохранения ширины `second` 140.5 перезагрузка восстановила значение и родителя `nested`; история Undo была пустой. На viewport 900×600 ширина страницы была 900 px, canvas прокручивался на 467 px до нижнего элемента.

Это исходная ручная проверка. Внешний Android-проект этим стендом не проверяется и не меняется.

## Автоматические проверки

Используется Playwright Test как dev-зависимость: [установка](https://playwright.dev/docs/intro), [браузеры и системные зависимости](https://playwright.dev/docs/browsers). После `npm ci` установить Chromium командой `npx playwright install chromium`, запускать `npm run test:browser`. Команда собирает frontend перед проверкой. Каждый тест получает новый временный каталог данных, свободный порт и чистый браузерный контекст. Временные сессии удаляются после остановки тестового сервера. При аварийном завершении процесса очистка не гарантируется.

В `tests/browser/editor.spec.mjs` автоматизированы B01–B11; B01/B07 объединены, B03 проверяет центр и край отдельно. B05 также проверяет индикатор назначения и его очистку. Дополнительно B12 проверяет тестовый Apply, неизменность handoff после поздней правки и восстановление черновика после перезагрузки; B13 — статус несохранённой правки сразу после Undo/Redo. Проверки выполняют реальные жесты мыши, проверяют серверный документ, точное восстановление baseline и геометрию относительно корня с допуском 0.05 CSS px. При сбое сохраняются screenshot, контекст и trace в `test-results/` (исключён из Git).

11 октября 2026: все 13 проверок Chromium и 15 Node-тестов прошли; синтаксис изменённых модулей проверен. Найден и исправлен статус после Undo/Redo: прежде он преждевременно показывал сохранение, теперь до записи сообщает о несохранённых правках. Ошибка воспроизведена отдельным тестом до исправления.

Полная приёмка R11 остаётся открытой: нужны потеря фокуса, циклы вложенности через UI, touch/pen и поведение в других браузерах. Внешний Android-проект и интеграция с Claude этими тестами не проверяются.

## Исправления редактора — числовой ввод и отмена жестов

Незавершённый ввод числа больше не удаляет свойство: последнее корректное значение остаётся в документе, рядом с полем видна ошибка. Исправление ввода снимает ошибку. Пустой точный размер снимает свойство и возвращает режим «По умолчанию»; свободная компоновка при этом сохраняет зафиксированную геометрию. Проверены 0, 0.5, 4000 и отказ для −1/4000.1. Переключение точного размера больше не закрывает раздел свойств при быстром обновлении панели.

Отмена drag/resize возвращает актуальный статус сохранения и убирает индикаторы. Даже если запись черновика завершилась во время жеста, после отмены виден её результат, а не старый статус. Добавлены B14–B18: неверный числовой ввод, пустое значение/границы, Esc/pointercancel, режимы размера и запись во время drag. Pointercancel подаётся браузерным тестом как событие; это подтверждает обработчик отмены, а не аппаратный touch/pen.

Итоговая проверка 11 октября 2026: 19 браузерных и 15 Node-тестов прошли; синтаксис изменённых модулей и `git diff --check` без ошибок. Во встроенном браузере отдельно подтверждены сообщение у неверного числа без изменения документа и видимое поле после переключения точного размера. Пользовательская сессия не использовалась.

## Клавиатура и узкая панель

Исправлена потеря фокуса при обновлении дерева и кнопок перестановки. Стрелки ↑/↓ выбирают узел, ←/→ переходят к родителю/первому ребёнку; Home/End выбирают начало/конец дерева. Tab включает один выбранный узел, Enter/Space сохраняют фокус. Кнопки «Раньше»/«Позже» работают повторно без мыши; на границе фокус переходит к доступной кнопке. Список «Родитель» сохраняет фокус после переноса; Ctrl+Z работает и в списках. Если Undo удаляет добавленный узел, фокус возвращается к существующему корню.

B19–B23 покрывают навигацию, повторную перестановку, отсутствие переполнения подписей и полей при 480/640/641/900 px, смену родителя с клавиатуры, Ctrl+Z и Undo добавления. Во встроенном браузере проверены выделение/фокус дерева и читаемость панели при 900×720. Длинные ID визуально сокращаются, полный ID остаётся в подсказке и доступном имени. Пользовательские подписи и подсказка перемещения — на русском.

11 октября 2026: все 24 браузерные и 15 Node-проверок прошли, синтаксис изменённых модулей и `git diff --check` без ошибок. Сессии изолированы; пользовательские данные и внешний Android-проект не менялись.

## Расположение: B24 — 11 октября 2026

В свободном режиме align/justify/gap отключены, но offsetX/Y доступны. Проверка B24 требует видимое объяснение и кнопку включения автоматической компоновки внутри раздела. После перехода проверяет редактирование трёх свойств, CSS макета, сохранение и Undo обратно до исходного документа. До исправления проверка воспроизвела отсутствие объяснения.

После исправления B24 прошёл, включая сохранённые значения и CSS alignItems/justifyContent/gap, Undo свойств и возврат исходного документа. Затронутые B17 и B21 также прошли; 18 Node-тестов успешны. Полный браузерный набор в этой итерации не перезапускался. Конкретная старая сборка Mealio не воспроизводилась, поэтому совпадение с наблюдением пользователя остаётся предположением.

## Компактная справка: B24/B25 — 11 октября 2026

По просьбе пользователя постоянные инструкции убраны. B24 теперь открывает справку о режимах возле переключателя «Компоновка» и включает auto из неё. B25 проверяет справку разделов и передачи: скрытое начальное состояние, Enter/Space, Escape, возврат фокуса, неизменность раскрытия раздела, отсутствие изменения модели/ревизии и переполнения при 480px. Иконка — небольшое i в кружке; инструкции открываются только по запросу.

## Рабочий цикл v0.3.0 — 11 октября 2026

Полный набор из 34 тестов Chromium прошёл в чистой временной копии исходников после npm ci. 21 Node-тест и синтаксис всех исходных модулей также прошли. Исходные пользовательские данные и внешний Android-код не изменялись.

B26 проверяет отказ review без проверки, загрузку эталона, явное подтверждение, сохранение доказательств и intent без автоматических frames. B27 — быстрый ввод/Apply и неизменность снимка. B28 — отказ записи, экспорт и восстановление локального черновика. B29 — конфликт двух окон и синхронизацию. B30 — импорт/восстановление прежней сессии и снимка. B31 — нативную область без декоративной геометрии. B32 — локальный Roboto, ограничения строк, letterSpacing и обрезку. B33 — наследование Roboto Flex и преобразование sp через fontScale без изменения передаваемого значения. B01/B07, B03 и B16 имеют объединённые/параметризованные сценарии, поэтому число тестов отличается от последнего ID.

Дополнительно Node-проверки подтверждают отказ второго сервера с теми же данными, сохранность снимков после перезапуска и импорта, восстановление baseline/reference/verification, запрет подмены fingerprint и обновление работающего сервера при смене версии пакета. Проверка baseline обнуляется после смены bridgeVersion; исторический снимок остаётся неизменным.

Сравнение с сохранёнными нативными метриками Mealio показало погрешность прямоугольников 18 текстов менее 0.016 dp в content-режиме. Визуальная сверка при этом выявила неполную типографику старого JSON и неправильные переносы: измерения не подтверждают точность реконструкции. Поэтому старый макет не объявлен проверенным; реализованы типографические параметры и обязательная сверка эталона пользователем. Этот эксперимент не является новым нативным переносом либо разрешением на изменение Mealio.
