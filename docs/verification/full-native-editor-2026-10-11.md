## Реальный Android-цикл

Создан отдельный минимальный Git-проект BridgeTest и отдельная рабочая копия. Оригинальный Composable содержит заголовок, описание в Card, кнопку, два одинаковых текста, строковый ресурс и текст из состояния; Light/Dark Preview. AGP 8.9.2, Kotlin 2.3.20, JDK 21.0.2; API 36, отдельный emulator-5584, 720×1280 px, density 320. Пользовательские сессии и Mealio не использовались для записи.

1. Prepare/build сформировали KSP-каталог двух настоящих Preview и проверенный APK. Native-run установил его на выбранный тестовый эмулятор и подключил кадр из 10 узлов.
2. Выбрано «Описание», runtime fontSize=14.0.sp. Найден один Kotlin-кандидат; два повторяющихся текста имеют по два кандидата, неоднозначность сохранена.
3. Через полный инспектор задано 18 sp, сохранена неизменяемая передача **в тестовом режиме**. Подтверждение сцены за пользователя не имитировалось.
4. Только в тестовой рабочей копии изменён Kotlin 14 → 18 sp. После сборки/native-run получен runtime fontSize=18.0.sp, новая ревизия и новый PNG.
5. До/После показывает настоящие исходный и новый кадры. Передача осталась побитово прежней по сериализованному JSON; исходный Git-проект не изменился. Проверена смена Dark Preview; ошибок JS страницы нет.

## Практические границы

Полноценный редактор настоящего UI проверен на минимальном Android-проекте. Свойства и структура сохраняют намерения; браузер не подделывает результат правки PNG. Kotlin меняется после отдельного поручения на перенос и разрешения кандидатов, затем нужен rebuild. Единственный кандидат не считается точным source mapping. Каталог Preview не перечисляет автоматически все состояния приложения; совместимость любых Gradle-конфигураций и автоматическое выделение UI-библиотеки не заявлены.
