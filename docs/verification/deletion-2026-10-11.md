# Доступное удаление элементов

Кнопка «Удалить элемент» перенесена из закрытого раздела «Перемещение» наверх инспектора. Delete удаляет выбранный элемент вне полей ввода; корень защищён. Контейнер удаляется вместе с детьми. Undo/Redo, сохранение черновика и неизменяемая передача агенту проверены на отдельной сессии.

Проверки: npm test — 46 тестов прошли; полный editor.spec.mjs — 37 прошли, один выявил конфликт Ctrl+Z в select. После исправления оба затронутых сценария (удаление и B22) прошли повторно. node --check и git diff --check успешны.

Обновлены сборка и оба установленных экземпляра плагина 0.8.1. Адрес действующего редактора сохранён; пользовательский session.json не изменён обновлением.
