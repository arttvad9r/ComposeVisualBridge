# Готовность к реальным проектам: первый этап

11 октября 2026. Выполнен шаг 1 [плана](../plans/development.md), в предусмотренном им варианте с передачей неподдерживаемых компонентов агенту.

## Изменения

- `bindCapture` сохраняет известное семейство шрифта. Регрессия Serif → Roboto воспроизведена и устранена; Roboto используется только при отсутствии известного семейства. Проектные темы и неизвестные гарнитуры остаются отдельной задачей.
- Подчёркивание читается из Kotlin, отображается и переносится обратно. Вертикальная прокрутка контейнера использует verticalScroll/rememberScrollState; снятие свойства удаляет этот модификатор.
- Явный stretch в адаптивном режиме заполняет поперечную ось естественных размеров детей у Column/Row. Числовые размеры сохраняются. HTML-renderer согласован с Kotlin; снятие заданного выравнивания возвращает значение по умолчанию.
- Общий контракт `public/compose-capabilities.mjs` используется редактором, адаптером и diff/передачей. TextField/Switch/Icon/Image, проектный Roboto Flex и изменение ресурсных/динамических текстов пока требуют работы агента. Они остаются редактируемыми и не исключаются из снимка.
- Сведения в UI открываются маленьким значком информации. Снимки получают необязательное transfer.requiresAgent; API handoff возвращает его структурированно, а отчёт объясняет причины. Старые снимки сохраняют совместимость.
- compose-plan возвращает strategy=adapter с полным автоматическим планом или strategy=agent с полным документом и причинами ручной работы. Частичный автоматический перенос не выполняется. Ручной путь по-прежнему требует поручения, проверки актуальных исходников и настоящего результата в Android.
