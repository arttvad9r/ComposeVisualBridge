# Проверка плагина Codex — 11 октября 2026

Подготовлен пакет v0.2.3, локальный marketplace и архив dist/compose-visual-bridge-0.2.3.tgz. Готовая сборка включена; потребитель не запускает npm и не размещает skills вручную. Node.js остаётся системным требованием.

## Проверено

- npm test: 18 проверок, включая прежние модель/API/CLI и новый цикл плагина; ошибок нет. После добавления архива целевой тест повторён на распакованном пакете и прошёл.
- node --check: scripts/plugin.mjs, scripts/package-plugin.mjs, tests/plugin.test.mjs.
- Оба packaged skill проходят штатный quick_validate.py. PyYAML установлен только во временном окружении валидатора, не в проекте и не в runtime-пакете.
- Архив содержит переносимый каталог и пакет; тест распаковывает его, копирует пакет в другой каталог с пробелами и выполняет setup без node_modules.
- Два конкурентных open дают одинаковые pid и URL, один повторно использует сервер. Данные другого проекта не выбираются; неверный ID сессии отклоняется.
- create делает новую сессию, не меняет предыдущую. read до Apply сообщает отсутствие снимка; после тестового Apply возвращает полный снимок. Поздний draft его не изменяет.
- stop завершает сервер с сохранением данных. Повторный read запускает сохранённую сессию; следующий open её использует. Удаление установленной копии пакета не удаляет данные.

## Codex и браузер

Отдельная временная попытка включить пакет только настройкой проекта не загружала его без установки; этот файл удалён, в итоговой реализации его нет.

Пакет запущен через managed CLI с отдельным BRIDGE_HOME=/tmp/bridge-plugin-browser-kjAPpb. Тестовый макет browser-scenarios.json; сессия screen-KURGx5. setup успешен. Во встроенном браузере Codex открыли URL на свободном порту 46197, изменили first.width на 144.5 и нажали «Передать агенту». Создан applied-1-fd58aca5, mode=test, revision=1. Команда read подтвердила ширину 144.5 и тестовый режим. После stop/open сервер выбрал порт 44219; handoff полностью сохранился. Браузер на новом URL восстановил ширину 144.5, успешный статус сохранения и совпадение черновика со снимком. После проверки сервер остановлен.

## Оставшиеся проверки

Установка кнопкой в приложении и автоматический onboarding callback после установки не проверены. Setup выполнен непосредственно из готового пакета; его инструкции и файлы распознаются Codex. Пакет ещё не опубликован в общем каталоге. Claude отложен из-за лимитов; macOS и Windows не проверены. Действующий цикл подтверждён в Linux; веб-превью не заменяет нативную проверку Android. Внешний UI-проект и пользовательская сессия Mealio не изменялись.
