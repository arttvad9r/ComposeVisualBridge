# Проверяемый браузерный редактор Compose

Требования: [спецификация](../specs/browser-compose.md). Пользователь поручил реализацию; дополнительные подтверждения этапов не требуются. Код основного внешнего проекта не меняется.

- [x] B1/B4: Kotlin-импортёр с координатами вызовов, ревизией и ресурсными/параметрическими выражениями; безопасный план переноса с сохранением неизменённых выражений. Проверка: Node-тесты парсинга, повторяющихся текстов, stale/reject и сохранения callbacks.
- [x] B2/B3: привязка проверенного захвата, построение модели для общего браузерного редактора и мгновенных жестов. Проверка: браузерные тесты реального перемещения элементов, текста, размеров и Undo; исходник остаётся отдельным.
- [x] B4/B5: перенос свойств/структуры и генерация новых экранов в отдельной копии; агент работает с тем же документом. Проверка: компилируемый Kotlin, ресурсные выражения/обработчики сохранены.
- [x] B2/B6: реальный цикл на отдельном Android-проекте — импорт, сравнение, браузерная правка, перенос, сборка и новый кадр. Не закрывать по одной рамке или синтетической PNG.
- [ ] B5/B7: каталог собственных компонентов/тем и подключение экрана из работающего приложения. Проверка на втором проекте и неоднозначных/динамических экземплярах.
- [ ] Итог: npm test, затронутые браузерные сценарии, node --check, пакет и установленная версия; перенести актуальные сведения в постоянные документы и удалить этот план после завершения всей задачи.

Первым проверяется двусторонний цикл на статической Compose-сцене. Он не заменяет приёмку конечного сценария B7. Если перенос/визуальное соответствие не подтверждаются, расширение интерфейса приостанавливается для исправления основы.

Проверка первого адаптера: [отчёт 11 октября](../verification/browser-compose-2026-10-11.md). B1–B5 отмечены только для перечисленного синтаксиса. Настоящий двусторонний цикл выполнен; строка B2/B6 закрыта после [нативной приёмки полного Mealio в 0.8.3](../verification/mealio-acceptance-2026-10-12.md) с двумя переносами, темами, callbacks и семью кадрами. Каталог custom-компонентов и сценарий B7 не закрыты.

В 0.9.0 добавлены каталог сохранённых экранов, пустой экран с запросом, палитра и debug-адаптер текущей сцены. [Отчёт](../verification/screens-plugin-2026-10-12.md): Subtrack собран, installed-пакет и обновление/откат проверены; B5/B7 остаётся открытым до настоящей проверки переходов/тем/динамического списка на втором проекте. План не завершён.
